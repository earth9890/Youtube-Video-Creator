# chapter: The yellow shirt
This is Dave. Dave woke up this morning able to understand every animal on Earth. Dave wants secrets. //
"Right. Tell me everything. I have a notebook." (@dave) //
So what would happen if you could talk to animals? / Would you learn their secrets, or hear a lot of very short sentences? //
The first thing Dave hears is a prairie dog, standing up on a mound, shouting about him. //
"Tall human. Yellow shirt. Coming this way." (@kid) //
Here is the plan. We'll climb from the smallest animal message to the biggest one nobody can read yet. / And we'll find out whether any of them have anything to say to Dave. //
Dave wrote the first line in his notebook. It says: they can see my shirt. //

# chapter: The prairie dogs
Is that real? Partly. In two thousand four, the biologist Con Slobodchikoff and two colleagues tested it in a colony of Gunnison's prairie dogs in Arizona. //
Three women of similar height walked through the colony ninety-nine times in total. / All three wore blue jeans and sunglasses. The only thing that changed was the colour of the shirt: blue, green or yellow. / It is the most consistent outfit in science. // [J]
They recorded eighty-two alarm calls from forty-eight marked animals. Then a computer measured the sound of each call. //
The calls for blue and for yellow were different, and so were the calls for blue and for green. But the calls for green and for yellow were not. //
The authors said that fits how prairie dogs see. They suggested the animals build labels for a predator's features into their calls. //
It was not perfect. The computer guessed the shirt from the call about fifty-five percent of the time. Chance would be thirty-three. // [J]
In a later study, the calls also differed for cut-out shapes of different sizes, like a circle, a square and a triangle. //
This isn't new. Prairie dogs already have different calls for a hawk, a human, a coyote and a domestic dog. / And in nineteen eighty, researchers showed vervet monkeys have different calls for a leopard, an eagle and a python. //
So a prairie dog has four ways of saying something is going to eat me, and one of them is human. // [J]
Researchers use a careful term for this: functional reference. / The call works as if it refers to the predator, but proving what the animal means is hard. The prairie dog is not available for comment. // [J]
Dave looks at the notebook. They can tell blue from yellow. It is not a secret. It is a shirt. // [J]

# chapter: The bees
Next, the bees. Karl von Frisch decoded their dance using glass-walled hives. It won him a share of the Nobel Prize in nineteen seventy-three. //
A bee that finds food flies back and dances. / In the dark hive, gravity stands in for the Sun. The angle of its waggle run, measured from straight up, / shows where the food is compared with the Sun. //
The length of the run shows the distance. A run lasting two and a half seconds means roughly two thousand six hundred metres. // [J]
If the flowers are within about fifty metres, the bee dances in a circle. That says close to the hive, but gives no direction. //
Dave asks a bee what the meaning of life is. //
"Two and a half seconds, that way, near the Sun. Please move." (@kid) // [J]
It is one of the most precise animal messages we have decoded. And it is a set of directions to some flowers. //
When a swarm needs a new home, hundreds of scouts dance for different sites. / In twenty eleven, researchers found a signal nobody had noticed: a very short buzz, delivered while head-butting a dancer. / It shortens and ends the dance. //
Bees settle a disagreement with a buzz and a head-butt. No further questions. // [J]
Dave writes in the notebook: bees give better directions than I do. // [J]

# chapter: Names
But do animals ever say who is who? / In twenty thirteen, researchers at the University of St Andrews played computer copies of signature whistles to wild bottlenose dolphins off the coast of Scotland. //
Each dolphin reacted only when it heard the copy of its own whistle. One of the authors called it the first case of naming in mammals. / We had assumed names were ours. Nobody had asked the dolphins. // [J]
In twenty twenty-four, a team recorded wild elephants in Kenya. / A computer model trained on four hundred and thirty-seven calls from ninety-nine callers could name the recipient of about a quarter of calls it had never heard. / Not a translator yet. A decent guesser. // [J]
Then they played calls to seventeen elephants. An elephant approached the speaker, on average, a hundred and twenty-eight seconds sooner when the call had been addressed to it. //
The same year, a team in Israel showed that marmoset monkeys use special calls to label each other, and answer more accurately when called. / Families seem to share a similar style, like a dialect. //
The elephant team was careful. The model might have picked up each caller's voice, and they are not sure where the name sits inside a call. //
So at least four species seem to label each other: humans, dolphins, elephants and marmosets. //
"Dave, do I have a name?" (@dave) //
Not that anyone has found, Dave. Nobody has found animals naming humans. // [J]

# chapter: The other direction
Talking goes both ways. So what about animals understanding us? / In twenty eleven, researchers at Wofford College reported that a border collie named Chaser had learned the names of one thousand and twenty-two objects over three years of training. //
She could even learn a new name by elimination. Given one unfamiliar toy among familiar ones, she picked it when she heard an unfamiliar word. //
The authors said this kind of understanding is normally credited to children. //
She understood a thousand and twenty-two words. She said none of them back. // [J]

# chapter: The whales
Now the hard one. Sperm whales make patterns of short bursts of clicks called codas. / In twenty twenty-four, a team led from the Massachusetts Institute of Technology analysed nearly nine thousand codas from whales off the island of Dominica. //
They found that codas combine four features: rhythm, tempo, and two finer features they named rubato and ornamentation. / These can be mixed freely into a large set of distinct codas. //
Some compared it to a phonetic alphabet. But the project's leaders were careful. One said the meaning of many codas remains unknown. //
So the whales have an alphabet with no dictionary. // [J]
Dave asks a whale what a coda means. It replies with a little rubato. // [J]
Dave looks at the notebook. It still says: they can see my shirt. //

# chapter: The twist
Here is the twist. Look at what has been decoded so far. Where the food is. Which shirt is coming. Who is calling whom. //
Mickey Pardo, one of the elephant researchers, says names are probably only one small part of those calls. / And the animals in these studies were not answering our questions. They were running their own lives. //
What would animals say to Dave? Our guess is four things. Where. What. Who. Danger. //
Dave writes four words at the top of the secrets page. //
"Where. What. Who. Danger. Dave, is that all there is?" (@dave) //
"Dave, that is most of life." (@doc) //
The animals are not hiding secrets. They are telling each other where things are, and who is who. //

# chapter: The prize
So could machines find more, or even talk back? / In May twenty twenty-four, a foundation and Tel Aviv University launched a challenge worth up to ten million dollars for talking with another species. //
The grand prize needs a kind of Turing test: the animal has to communicate independently, without recognising that it is communicating with humans. / A prairie dog would never pass. It announces the human before the human arrives. // [J]
There is also a hundred thousand dollar prize every year for the best progress. / Four finalists in twenty twenty-five, from the United States, Germany, France and Israel, were working with dolphins, nightingales, cuttlefish and monkeys. //
So far, nobody has claimed the grand prize. //
Dave decides to enter. He has a notebook. // [J]
