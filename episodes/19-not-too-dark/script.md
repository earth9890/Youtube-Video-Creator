This is Dave. / Dave took four hundred group photos. / He's in none of them. // [J]
In the old ones, his face is a shadow. / Dave's verdict: / "I'm too dark." //
Is Dave too dark, / or is the photo wrong? //
Suspect one: / Dave's skin. / Dave has already confessed. // [J]
In two thousand, Nina Jablonski compared skin colour with satellite maps of ultraviolet. //
Strong sun, darker skin. / Weak sun, lighter skin. //
Dark skin guards folate, which growing babies need. / Light skin lets weak sun make vitamin D. //
Every shade is a setting / for a different sun. / Dave's is set / for a strong one. // [J]
"Then why am I a shadow?" //
Suspect two: / the camera. //
In the fifties, labs tuned colour prints to one photo: / a white woman called Shirley. //
If Shirley looked right, the print was right. / Darker faces / lost detail. //
Parents complained. / Nothing changed. //
Then chocolate makers complained: / milk and dark looked alike. //
So Kodak improved the film, / then ate the test subjects. // [J]
And photos of dark skin got better / by accident. // [J]
(slow) Group photo four hundred and one. / Dave taps his face on screen. / The camera sets itself / for Dave. //
(slow) You are not too dark. / Cameras were set for Shirley. // Set yours for you.
