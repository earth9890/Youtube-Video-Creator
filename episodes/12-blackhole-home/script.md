# What If We Live Inside a Black Hole? — v3 script (script-writer.md). Narrator: calm honest guide. Dummy: Dave. Runner: "Probably."
Right now, you're inside something. / A room, a city, a planet, a galaxy. //
Physicist Nikodem Poplavski thinks the list keeps going. / (slow) The next item / is a black hole. //
Black holes have one rule. / Stuff goes in, nothing comes out. / Not light, not information, / not the sock Dave threw at one. // [J]
This is Dave. / Dave would like to test the theory. / Personally. // [J]
A small black hole would stretch him like spaghetti. / But fall into one the size of a universe, / and the pull is so gentle, / Dave crosses the edge without spilling his tea. // [J]
No bump. No alarm. No sign saying welcome to the inside. // [J]
"So I'm inside one right now?" / Probably. // [J]
Here's the clue. / In twenty twenty-five, the Webb telescope checked two hundred and sixty-three of the oldest galaxies. / Two out of three spin the same way. // It should be half and half. /
As if they all got the same twist / from whatever they were born inside. //
Other astronomers: / (low) "Small sample. / Probably nothing." /
Dave: / "Probably?" // [J]
(slow) But if they're wrong, / every black hole up there / is a door. //
Right now, you're inside something. / A room, a planet, a galaxy, / a black hole. //
(slow) Looking out / at all the others.
