This is Dave. / Nothing good ever happens to Dave. //
His friend Sam gets every lucky break. / Dave hears about them. // [J]
Is Dave cursed? //
Dave buys a lucky charm. //
Psychologist Richard Wiseman tested lucky charms. / Zero effect. //
A few felt unluckier, / and were glad to give it back. // [J]
"So I'm just born unlucky?" //
Wiseman doubted it. / He gave lucky and unlucky volunteers a newspaper. / Count the photos. / Dave takes two minutes. / Lucky people, seconds. //
Page two said, in two-inch letters: / stop counting, there are forty-three photographs. //
The unlucky ones tended to miss it. / Half a page. // [J]
Halfway through, another ad: / tell the experimenter you saw this, and win two hundred and fifty dollars. //
Dave missed that too. / Still counting. // [J]
"So I look harder?" / (low) "No." // [J]
He was busy counting. / Lucky people see what's there, / not just what they're looking for. //
Fair warning: / pop science, not a big trial. / But it's cheap to test. //
Lucky volunteers broke routines. / One picked a colour before parties, / and only talked to people wearing it. // [J]
(slow) So tomorrow, change one routine. / New route, new seat. / Look up. //
(slow) Nothing good happens to Dave? / Two good things did, / in two-inch letters. //
(slow) You are not unlucky. / You were just counting.
