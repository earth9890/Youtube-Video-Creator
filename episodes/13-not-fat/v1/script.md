# Episode 13 trial: "You Are Not Fat" (1 min). Narrator: calm, slightly-too-honest guide. Test dummy: Dave. Runner: "Fair."
# Sources: body water ~60 % (adult, USGS/Guyton); atoms ~99.9999999 % empty -> humanity at nuclear density ~2 cm3 (a sugar cube);
# Meerman & Brown, BMJ 2014 "When somebody loses weight, where does the fat go?" (10 kg fat -> 8.4 kg exhaled as CO2, 1.6 kg water; survey of 150 doctors/dietitians/trainers: most said "energy/heat");
# Meerman lost ~15 kg himself first; Spalding et al., Nature 2008: adult fat-cell number set by adolescence, cells shrink not vanish.
You are not fat. / You're about sixty percent water, some calcium, / and a lot of empty space. // [J]
Squeeze the empty space out of every human alive, / and all eight billion of us fit in a sugar cube. //
Fat isn't what you are. / It's what you're carrying, / stored energy waiting for a reason. //
This is Dave. / Dave lost ten kilos of fat. / He'd like to report them missing. // [J]
Ask doctors and trainers, and most say: / (fast) burned off as heat. //
In twenty fourteen, physicist Ruben Meerman lost fifteen kilos himself, / and followed the atoms. //
Eight point four of Dave's ten kilos / leave through his mouth, / as carbon dioxide. // The rest leaves as water, / as sweat, pee, / and tears. // [J]
Dave breathed out his belly. // [J]
Some of it is now part of a tree. // [J]
And the fat cells don't leave at all. / Lose weight, and they just shrink, / like deflated balloons, / waiting. // [J]
"So I just breathe faster?" / (low) "No." /
Breathing harder only makes you dizzy. / Breath can only carry out / what your muscles already burned. //
"Fair." // [J]
(slow) So, / you are not fat. / You're water, empty space, / and a little stored energy / you're slowly breathing back out.
