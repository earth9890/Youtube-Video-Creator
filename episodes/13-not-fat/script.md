But ten kilos is a whole watermelon of Dave, / and stuff can't just vanish. / So where did it go? //
Dave asks the experts. / Most doctors and trainers say: / (fast) it burned off as heat. //
But heat weighs nothing, / and ten kilos didn't leave as a warm feeling. // [J]
(fast) Turned into muscle? Can't. / Pooped out? That's mostly bacteria and leftovers. // [J]
The case went cold. //
Until twenty fourteen, / when physicist Ruben Meerman lost fifteen kilos himself, / and followed every single atom. //
The culprit was right under Dave's nose: / his mouth. // [J]
Eight point four of the ten kilos / left as carbon dioxide. / Dave breathed out his belly. // [J]
The rest left as water. / Sweat, pee, / and tears. // [J]
"So I just breathe faster?" / (low) "No." /
That just makes you dizzy. / Breath only carries out / what your muscles already burned. //
And one more thing. / The fat cells never left. / They just shrank, / and they're waiting. // [J]
(slow) So, / you are not fat. / You're a very slow exhale. /
