# YouTube Video Creator — Black Hole Life

End-to-end pipeline for hand-drawn whiteboard / stick-figure motivational videos: script → deep voiceover → HyperFrames build → 4K render → titles, thumbnails, channel art.

| Folder | What |
|---|---|
| `skill/whiteboard-video-studio/` | The Claude Code skill (workflow, research-backed craft playbook, engine, scripts). Source of truth lives in `~/.claude/skills`; run `./sync.sh` to refresh. |
| `episodes/NN-topic/` | One video each: `script.json` (sentences + pauses), `scenes.js` (whiteboard animation), `assets/voice.wav`, `assets/clipt.json`, `index.html` (built), `package.md` (titles/description/tags), `thumbnails/`. |
| `logos/`, `banners/`, `thumbnails/` | Channel art (generated by `src/gen.py`, `src/thumbs.py`). |
| `music/` | MusicGen beds (30 s seeds, looped by the mixer). |
| `gallery/` | Visual test of every engine prop (`scenes.js` → snapshots). |

## Rebuild a video
```bash
cd episodes/01-procrastination
~/.venvs/tts/bin/python ../../skill/whiteboard-video-studio/scripts/voice.py script.json assets --speed 0.8   # voice (Kokoro, local)
python3 ../../skill/whiteboard-video-studio/scripts/build.py .                                               # index.html
npx hyperframes check && npx hyperframes render --quality delivery --resolution 4k --output out-4k.mp4
```
Renders (`*.mp4`) are not committed.

## Writing a new video (since 2026-10-13)
Funny explainers (space, science and history "what if" topics) follow **`skill/whiteboard-video-studio/references/script-writer.md`**. It was built from a 54-transcript study of Zenn, Past Tense, Sam O'Nella, Casually Explained, Half as Interesting, OverSimplified, Kurzgesagt and Sciencephile; the evidence is in `references/research/`.
```bash
cd episodes/NN-topic
python3 ../../skill/whiteboard-video-studio/scripts/script_lint.py script.md            # must PASS (Joke Law, density, callback, numbers as words)
~/.venvs/pocket/bin/python ../../skill/whiteboard-video-studio/scripts/voice.py script.md assets --lead 0.4 --tail 1.5 --speed 1.0   # Pocket TTS "jean"; voice.wav is regenerated, not committed
python3 ../../skill/whiteboard-video-studio/scripts/build.py . && ../../skill/whiteboard-video-studio/scripts/finish.sh . none   # 4K render
```
Order: script text, then voice-only mp3, then visuals. Start with a 1-minute trial before any long video.

Thumbnails follow **`skill/whiteboard-video-studio/references/thumbnail-designer.md`**. It is built from 1,260 thumbnails of the same 8 channels, each scored by views against its neighbours, and its evidence is in `references/research/thumbnails/`.
```bash
python3 ../../skill/whiteboard-video-studio/scripts/build.py . --thumb thumbnails/thumb-c.js thumbnails/c.png
~/.venvs/pocket/bin/python ../../skill/whiteboard-video-studio/scripts/thumb_check.py thumbnails/c.png thumbnails/d.png --space   # lint + c_grid.jpg (yours among real hits; not committed)
```
