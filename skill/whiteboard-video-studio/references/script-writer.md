# Script writer — funny explainers that actually explain

> Built 2026-10-13 from 54 transcripts (top videos of Zenn, Past Tense, Sam O'Nella, Casually Explained, Half as Interesting, OverSimplified, Kurzgesagt, Sciencephile), ~8 h of narration. Evidence, per-channel reports, measurements and tools: `references/research/README.md`.
> **This file is the law for every script.** It overrides script-guide.md §0.35 (old sarcasm rules). Run `scripts/script_lint.py` before generating any voice.

## 0. The one diagnosis
Our rejected black-hole script had ~12 gags in 60 s and **every one was about the viewer's life, not the topic**: Mondays, traffic, Wi-Fi, the family WhatsApp group, "cosmic Kinder Joy". Across ~8 hours of the best channels that kind of joke appears **zero times**. Their jokes are the fact itself, said in a funnier shape.

**THE JOKE LAW — every joke must pass both tests:**
1. **Delete test:** remove the joke → the viewer loses information or a picture. (If nothing is lost, it was decoration. Cut it.)
2. **Move test:** could this joke be pasted into a video about a different topic? If yes, cut it.

| Bolted-on (banned) | Built from the fact (good) |
|---|---|
| "A black hole eats everything. Stars. Planets. Your weekend plans." | "Black holes have one rule. Stuff goes in. Nothing comes out. Not light. Not information. Not that sock you threw at one." |
| "Once you're in, you can't get out. Like the family WhatsApp group." | "Fall into one big enough and you'd cross the edge without spilling your tea." (= tidal forces are gentle) |
| "Science is mostly maybe, in a lab coat." | "Most astronomers say: probably nothing. Wait for more data. / Fair." (= real doubt, concrete) |
| "Like a cosmic Kinder Joy. Surprise! It's us." | "No bump. No sign saying 'Now leaving reality.'" (= no event-horizon sensation) |

## 1. The narrator (pick once per channel, never break it)
Every comedy channel's narrator is a **character**: Sam O'Nella = menacing older brother, Casually Explained = calm instruction manual, HAI = petty vain host, Sciencephile = evil AI, Zenn = calm dry guide. The joke lives in the gap between the voice and the content.

**Black Hole Life narrator = the calm, slightly-too-honest tour guide.** Speaks like a museum audio guide (polite, measured, "Now," "Here's the thing,") about absurd, enormous or grim things — and never reacts to how absurd they are. Allowed asides: "Seriously." "This one's rough." "Fair." "Relaxing." Never: "LOL", "Boom!", "Surprise!", exclamation energy, laughing at its own joke, explaining the joke.

**Plus one test dummy per video:** a named stick figure (e.g. Dave) who does the experiment so the viewer can watch the physics happen to someone (Sciencephile's Jon, HAI's Amy, Zenn's named mice). He has one petty trait and suffers the consequences. He may talk back; the narrator answers flatly.

## 2. Shapes

### 2.1 One-minute short (150–190 words, ~60–70 s)
| Beat | Time | Job |
|---|---|---|
| Hook | 0–8 s | "You" in a concrete present moment, or the test dummy doing something, then a flip of scale. The title claim/question is spoken by 0:08. |
| Reframe | 8–15 s | Deny the obvious ("It isn't a hole. It's…"), set the one rule of the topic. |
| Mechanism | 15–30 s | One idea, demonstrated on the test dummy or on "you" physically (falling in, standing on it). Earth anchor → cosmic twist. |
| Evidence | 30–45 s | One named, numbered clue ("In 2025, // the Webb telescope checked 263 galaxies…") + a 3–5 word restatement. |
| Honest doubt | 45–55 s | The sceptic as a character with a concrete reason, then a one-word undercut ("Fair."). |
| Callback | 55–65 s | Re-run the opening image with the new knowledge. Quiet turn or one dry button. No new joke. |
Joke beats: **4–6**, none in the last ~8 s except a callback button. One runner word/phrase planted in the first 15 s and paid off at the end.

### 2.2 Long form (8–10 min, ~1,500–1,800 words)
| % | Beat |
|---|---|
| 0–6 | Cold open (hook templates §3) |
| 6–8 | Title question + one-line promise naming 2–3 things the answer changes (= the sections) |
| 8–30 | §1 the mechanism, demonstrated (test dummy / "you"); jokes densest here |
| ~30 | Reversal re-hook: "But consider…" / "But here's what's fascinating" |
| 30–60 | §2 root cause / escalation: weird → weirder; one serious 30–45 s stretch for the most awe-inspiring fact |
| ~60 | Best analogy of the video ("less like X, more like Y") |
| 60–80 | §3 darkest / strangest / most personal; "the part nobody talks about" |
| 70–85 | Twist: fake ending ("So that settles it, right? / Well, / not quite.") or "that's not what X actually said" |
| 85–100 | Why it matters to you + callback to the opening image, changed. Last 15 % joke-free or callback-only. |
Re-hook every 45–75 s. Joke beats **2–3 per minute** overall (comedy channels run 3–6; Zenn 1–2). Never > 25 s without a joke or a "huh" fact, except the one deliberate serious stretch. Sections end on a punch, never on a bare fact.

## 3. Hook templates (fill the brackets; never open with a definition)
1. **Switch flip** (Zenn, 8M): "Tonight, you'll [modern mundane act]. / You won't think twice. // For [99 % of history / most of the universe], [that thing] didn't exist." → sensory picture → "So what did they do instead?"
2. **Nesting list** (space topics): "Right now, you're inside something. / A room. / A city. / A planet. / A galaxy. // [Some physicists] think the list keeps going." → the claim as the next item.
3. **Perfect setup → disaster** (Zenn, 5M): "[N subjects] got everything: [3 comforts]. // [Time] later, [opposite outcome]. / And it wasn't [the obvious cause]."
4. **Odd one out**: "[3 things that do X perfectly]. // And then there's us." → 3 blunt failures → "What if…"
5. **Obvious question**: "We know [A]. We've [B]. We've even [absurd C]. // So why hasn't anyone just // [obvious move]?"
6. **Doomed mission** (HAI): "This is [Dave]. Dave wants to [simple goal]. / Dave is going to fail. / Not because [funny wrong reason] (though, yes, [true]). Because [real reason]."
7. **Everyday version → cosmic version** (Sciencephile): "[Ordinary X]s are everywhere: [2 normal], [1 dumb]. // But there's a family of [X]s that breaks the rules."
8. **One rule** (space): "[Thing] has one rule. / [Rule]. // [List of what it applies to, last item petty]."
Hooks put a concrete image or question first, the claim second, and never a date or name in the first sentence.

## 4. Joke recipes (ranked by how often the benchmarks use them)
Each is `[setup] → [turn] → [punch]`. The punch is the **shortest sentence in its paragraph and comes last**.
1. **Deadpan undercut** — serious build (2–3 clauses) → beat → 1–3 word deflation. "Ours were retrofitted. / Badly." "Could be a coincidence. Could be a very large hint."
2. **Modern translation** — ancient/cosmic fact described with an everyday object or institution that *explains* it. "A prototype that never got its final update." "Generosity is the savings account."
3. **Understatement** — catastrophe or huge number in tiny polite words. "Awarded a light nine point four million." "To put it mildly, // not practical." "Relaxing."
4. **Reductive redefinition** — beloved/grand thing "is just" its unglamorous mechanism. "Cooking is pre-digestion." "A black hole is a star that died so hard it folded space shut."
5. **List with a broken last item** — 2–4 normal items, same rhythm, last breaks category (petty, literal, self-own). "Not light. Not information. Not that sock you threw at one." Read the list **fast**, beat before the last item.
6. **Absurd specificity** — one oddly exact object instead of a category. "No sign saying 'Now leaving reality.'" "Eight-legged gummy bears."
7. **Test-dummy demo** — the physics happens to Dave; one line of his reaction. "'Shouldn't I be spaghetti?' // No."
8. **Fake dialogue / sceptic as character** — compress a stance into casual speech, 2–4 lines, last one a one-word punch. "Other astronomers: 'Small sample.' / Dave: 'Probably?'"
9. **Personified physics** (Kurzgesagt) — particles/cells with human motives, still accurate. "Electrons really enjoying their private space." "The immune system chose violence."
10. **Literal / fake definition, then the real one** — "Atmospheric freezing. That's when the atmosphere freezes. / You're welcome." Then the true definition straight.
11. **Repetition loop with twist** — condition → outcome, ×2, absurd condition → same outcome. "Too fast. Black hole. Not uniform. Black hole. Mercury in retrograde. Black hole."
12. **Misdirection on the last word** — sentence points at an obvious target → long beat → the target is us. "One craving we still have trouble admitting: // each other."
13. **Fake ending** — neat resolution → "right?" → reopen with the strongest point.
14. **Runner / callback** — plant a phrase in the first 15 s, reuse it 2–3×, last time in a context where it shouldn't fit (one level higher). "Probably." / "Fair." / "Dave."
15. **Perspective flip** — our normal seen from their world. "Somewhere, someone is looking at our sky and wondering which side is the inside."

**Banned joke types:** generic relatable complaints (Mondays, traffic, bills, Wi-Fi, WhatsApp, "your ex"), random pop-culture similes with no explanatory payload ("cosmic Kinder Joy"), "Boom!/Surprise!" as a punch, sarcasm that makes the science look pointless ("science is mostly maybe"), roasting real nations/groups, jokes about illness or the viewer's real suffering.

## 5. How a fact is delivered (the fact sandwich)
1. **Question or expectation first.** "You'd expect it to crush you." / "So where does it go?"
2. **Earth anchor, then the cosmic twist.** "On Earth, X. Out there, Y, because Z."
3. **Named evidence, year first, then a beat:** "In 2010, // physicist Nikodem Popławski…" One per section; never "some scientists" alone.
4. **Number → household unit.** "Ten thousand kilometres — about fifty million frozen bananas." Numbers **as words** in script.json.
5. **3–5 word restatement / verdict:** "Not X. Y." "This wasn't insomnia. This was normal." "It isn't a hole. It's a place."
6. **Then (optionally) the joke** as the last clause or the next short sentence.

## 6. Line rules
- Mean sentence 10–13 words; **20–30 % of sentences ≤ 5 words**; at most 1 in 8 over 20 words. Pattern: long, long, short.
- Fragments are punches and awe: "Light." "Everything." "Fair." "Earth. Warm and pleasant."
- "You" is **physical**: you standing on it, falling in, holding the flashlight. Never "you" + life complaint.
- Rhetorical questions only at the hook and section pivots (≤ 1 per 30 s).
- Lists of 3; anaphora for emphasis ("It takes the young. It takes the old.").
- Transitions (pick, don't invent filler): "Here's the thing." "Now," "But here's what's fascinating." "And it gets stranger." "Here's the part nobody talks about." "So, what killed it?" "Now, where was I? Oh yeah, [3-word recap]."
- Banned words: basically, actually (except in titles), "in this video", "welcome back", "smash that like", "Boom", "Surprise", "LOL", "literally" (unless the idiom is literally true).
- Every claim checkable; doubt stated concretely (who says no, and why), once, late.

## 7. Delivery — when to stop, when to go, low vs high
Measured on 9 narrator videos (whisper word timing + pitch tracker; full tables `references/research/data/delivery_table.txt`, report `references/research/delivery-and-tts.md`) and 160 test clips of Pocket TTS jean (`references/research/data/run2.txt`, `results.tsv`).

### 7.1 What the pros do (funny narrators: Sam O'Nella, Casually Explained, Half as Interesting)
1. **Normal gaps are tiny: 0.1–0.3 s** between lines. Long beats (≥ 0.6 s) are the rarest 10 % — that's why they land.
2. **The long beat goes AFTER the joke** (most common spot for their longest gaps), not before it: 0.35–0.45 s after a normal punch, 0.7–1.0 s after the section's biggest joke.
3. **Setup → full-sentence punch: no beat.** The punch just flows on (0.17 s, same as fact→fact).
4. **One-word / short punches (≤ 7 words) are the exception:** 0.5–0.9 s beat before, said ~25 % faster, ~2 semitones lower, flatter. "Nope." "Fair." "Personally."
5. **Punchlines are deadpan:** same speed, pitch and falling end as facts. Never act out the joke.
6. Every statement ends ~3.5 st lower on its last 3 words; questions fall less; character voices rise.
7. Setups slightly slower/higher (−7 %, +0.4 st).
8. **Section changes are marked by speed, not silence:** ~12 % faster, normal gap, visual transition does the work.
9. Character voices: different pitch, rising end, ~14 % slower; 1–2 s reaction beats between dialogue lines.
10. **No silent cold open:** first word within 0.5 s; hook ~5 % slower; straight into the body.
Funny pace: 197–239 wpm (jean at speed 1.0 is already there, ~7.5 syll/s). Serious channels: 161–192 wpm, gaps 0.12–0.14 s, dramatic lines ~9–16 % slower.

### 7.2 What our TTS can actually control
| Lever | Works? |
|---|---|
| Gap between clips (`/` `//`, line ends) | **Yes — exact** (after the 2026-10-13 trim fix; before it every gap was +0.5 s, which made us sound slow and documentary) |
| Splitting a sentence into clips at `/` | Yes — the first part ends falling (−1 st), natural for a beat |
| Speed per clip `(fast)` / `(slow)` (atempo 0.9–1.1) | Yes, pitch unchanged |
| Pitch per clip ±1 st | Yes, sounds like the same speaker |
| Pitch ±2 st | Sounds like another speaker → use only for **character quotes** |
| "?" | Weak yes (end rises in 2 of 3 seeds) — keep it on real questions |
| "!", "...", "—", ALL CAPS, quotes, commas, mid-line punctuation | **No effect** (or random). Don't rely on punctuation for timing — use `/` `//`. |
| Seed | Deterministic; ±0.1 s / ±0.5 st between seeds |
Jean's in-line melody is flat (2 st vs humans' 5–8 st) — no lever fixes that; vary line-to-line with speed, short punches and character pitch instead.

### 7.3 script.md markup (voice.py reads it directly)
Write `script.md` (one beat-group per line, `#` comments) and run `voice.py script.md assets --lead 0.4 --tail 1.5 --speed 1.0`. It writes `script.json` (one entry per clip: text, gap, speed, semitones) and the audio. **Clip numbers for `W(clip, word)` cues are the clips in that script.json**, not the md lines.
| Mark | Effect |
|---|---|
| line end / `/` | new clip, 0.2 s gap |
| `//` | new clip, 0.7 s gap — after punches, before short punches and big reveals, at most ~1 per 5 s |
| `(fast)` / `(slow)` | 1.08× / 0.9× for the rest of the line (asides / awe lines) |
| `"quoted"` | character voice: +2 st, 0.95×. Add `(low)` on the line for a second character (−2 st) |
| `[J]` at line end | marks a joke beat (lint density); a ≤ 4-word last chunk becomes a deadpan short punch (−1 st, 1.05×) |
Rules of thumb: lists inside ONE chunk with commas (read fast, no beats), `/` only before the broken last item; `//` after the punch, not before (except one-word punches); dialogue lines get `/` between speakers; the ending gets `(slow)` and `/` between short phrases.

## 8. Writing process (do every step; it's what separates a script from a list of facts)
1. **Premise in one sentence** + the one rule of the topic + the twist. If there is no paradox or twist, find a different angle.
2. **Fact mine (10–15 facts)** with sources. For each fact ask: What's absurd about it? What's the household-scale version? What would happen to Dave? What's the literal reading of its name? Who was wrong about it and how? What's the petty version? — write 2–3 joke candidates *from the fact itself*.
3. **Pick the narrator move + test dummy + runner phrase.**
4. **Beat sheet** (§2) with times; assign facts to beats; plant callback in the hook.
5. **Draft fast**, then **punch-up pass**: for every fact line, can its last clause become a punch (recipes 1–6)? Is the punch the shortest sentence, last?
6. **Cut pass**: run the Joke Law on every joke; kill any joke that fails delete/move. Kill filler.
7. **Delivery pass** (§7.3): `//` after punches, `/` before broken last items, `(fast)` asides, `(slow)` ending, quotes for characters, `[J]` on joke lines.
8. **Lint**: `python3 scripts/script_lint.py script.md` — fix every FAIL.
9. **Self-score** (§9). Below 32/40 → rewrite the weakest beat, not the whole thing.
10. **Owner reads the text first** (1-min trials). Voice only after approval; visuals only after the voice is approved.

## 9. Score card (0–4 each, need ≥ 32/40)
| # | Test | 4 = |
|---|---|---|
| 1 | Hook | concrete image/question + claim spoken by 0:08; I'd keep watching |
| 2 | One clear idea | a viewer could explain the mechanism to a friend afterwards |
| 3 | Joke Law | every joke passes delete + move tests |
| 4 | Joke density | 1-min: 4–6 beats; long: 2–3/min; no gap > 25 s |
| 5 | Narrator voice | consistent calm-honest guide; zero exclamation energy |
| 6 | Test dummy / you | the physics happens to someone we can see |
| 7 | Evidence | named + numbered; doubt is concrete |
| 8 | Escalation | each beat weirder/bigger than the last; one twist |
| 9 | Callback ending | opening image returns changed; no new joke |
| 10 | Rhythm & delivery | 20–30 % short lines; marks placed by §7 rules |

## 10. Worked example — black hole, 1 minute (episode 12 v3, `script.md`, 66 s)
Uses: nesting-list hook, one rule, test dummy Dave, runner "Probably.", fact sandwich, sceptic as character, callback. Lint: PASS.
```
Right now, you're inside something. / A room, a city, a planet, a galaxy. //
Physicist Nikodem Poplavski thinks the list keeps going. / (slow) The next item / is a black hole. //
Black holes have one rule. / Stuff goes in, nothing comes out. / Not light, not information, / not the sock Dave threw at one. // [J]
This is Dave. / Dave would like to test the theory. / Personally. // [J]
A small black hole would stretch him like spaghetti. / But fall into one the size of a universe, / and the pull is so gentle, / Dave crosses the edge without spilling his tea. // [J]
No bump. No alarm. No sign saying welcome to the inside. // [J]
"So I'm inside one right now?" / Probably. // [J]
Here's the clue. / In twenty twenty-five, the Webb telescope checked two hundred and sixty-three of the oldest galaxies. / Two out of three spin the same way. // It should be half and half. /
As if they all got the same twist / from whatever they were born inside. //
Other astronomers: / (low) "Small sample. / Probably nothing." /
Dave: / "Probably?" // [J]
(slow) But if they're wrong, / every black hole up there / is a door. //
Right now, you're inside something. / A room, a planet, a galaxy, / a black hole. //
(slow) Looking out / at all the others.
```
