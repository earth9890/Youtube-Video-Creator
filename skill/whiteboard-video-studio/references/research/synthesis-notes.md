# Synthesis notes (condensed agent reports)

## Comedy benchmark — Sam O'Nella (SO) + Casually Explained (CE)
- Density: SO Pirates 5.9 jokes/min (info:joke 1:2.7); CE Cooking 6.5/min (1:3). Max no-joke stretch ~20–25 s; up to 40 s only for the core useful explanation, closed by a strong joke.
- Placement: CE = punch in last clause of the SAME sentence as the fact ("this won't do X but it will do petty Y"). SO = fact straight, then 1–3 tags/skit. Sections never end on a fact.
- Joke types (count SO/CE): character skit/fake dialogue 30/14; fake definition "X is French for Y" 6/50; anticlimax 18/24; narrator self-own 14/16; roast group/viewer 10/25; absurd specificity 15/18; modern anachronism 16/12; ironic fake advice 4/14; deadpan understatement 14/6; broken-last-item list 8/14; wordplay/literal 10/10; misdirection last word 6/8; escalation run (3+ beats, flat close); callback +1 level; visual completion (line stops, drawing finishes it).
- Narrator = a character (SO: menacing older brother "hey kids", god-narrator who punishes talking-back figures; CE: calm instruction-manual register vs petty content: "nevertheless", "relatedly", "the good news is").
- CE "good news pivot": myth → "in reality" → "the good news is" → absurd advice from the real fact.
- Delivery: wpm ~205 both. Riff/list videos fast (220+, few pauses); deadpan one-item videos slower (190, 5–7 long pauses/min). SO: beat BEFORE punch, no pause after, rushed escalation lists. CE: short `/` before punch word, long `//` AFTER punch (laugh room), then reset word ("Anyway."). Punch said flat, not louder. Asides fast, unpaused.
- Avoid: bolted-on relatable gags (Mondays/traffic/Wi-Fi/WhatsApp) not derived from the fact; explaining/laughing at joke ("Surprise! It's us"); unconnected one-liners with no escalation/callback; section ending on bare fact; "Boom!" as punch.

## Half as Interesting (HAI) + OverSimplified (OS)
- HAI = one opinionated petty narrator explaining one system; OS = cast of characters acting out facts as dialogue (fact inside the dialogue, scene's last line = punch, narrator returns plain).
- Hooks: tiny person → huge consequence → name thing → joke → bigger mystery → "So today…"; Doomed mission ("This is Amy. Her mission is doomed. Not because [wrong funny reason] (though true). Because [real reason]"); Grand→flat ("height of civilization. Let's have a war."); cold-open sketch + grim deadpan narrator undercut.
- Density ~3 jokes/min (HAI 1 joke : 3 info lines); OS setup sections 1:1, war sections 1:8; deliberate serious stretches (≤75 s) for atrocity/climax, followed by a big joke.
- Types extra: runner/catchphrase reused 3× with last in wrong context; understated adjective on big number ("a light 9.4 million"); "Except no." fake-out; fake fact then retraction ("I made that last one up"); "less like [obvious], more like [better]" explanatory analogy; genre parody; dark juxtaposition; voiced viewer objection; one-word undercut fragments "Maybe." "Fair enough."
- Structure HAI 8-min: hook 0–8% → promise → mechanism demo as narrator's own errand → "But, consider…" reversal ~30% → root cause → analogy ~60% → conflict → callback ~80% → literary button. 1-min: character+premise 10s → mechanism 15s → evidence 15s → doubt 10s → callback 10s.
- Transitions: "So, what is X?", "But, consider…", "All of which is to say", "Next up:", "Meanwhile", "Now where was I? Oh yeah, [3-word recap]", "Guess who's back?"
- Rhythm: median sentence HAI ~15 words, OS 8–14; 33% ≤5 words in dialogue-heavy. Lists read fast without commas, worst item last.
- Delivery: dialogue = slower + more silence (185 wpm, 6.5 pauses/min); narration/lists fast 220. Long pause right AFTER section-ending punch. One-word undercut: pause both sides. Escalation lists: zero pauses. Asides fast.
- Steal: protagonist w/ goal (1 named stick figure); facts as 3–5 line exchanges ending on one-word punch; joke must carry information (delete-test); one runner from first 20 s paid off 2–3×, last in final line; skeptic as a character; one serious awe stretch; end on callback + dry button.
- Avoid: "like a [random pop thing]" similes with no explanatory payload (cosmic Kinder Joy); joke every line w/o breath; wonder w/o reversal; ending on a new joke.
- Demo idea: "This is Dave. Dave lives in a house, in a city, on a planet, in a galaxy, // inside a black hole. // Probably." Runner "Probably". Skeptics: "Small sample. Probably nothing." Dave: "Probably?" Ending: every black hole has its own Dave. Also going to work.
- Fact caution: JWST spin study ~263 galaxies, ~2/3 (60–70%) — say "most".

## Kurzgesagt (KZ) + Sciencephile (SP) — space benchmark
- SP ~3 jokes/min (info:joke 3–4:1), longest dry 45 s for core science ladder. KZ ~0.7/min, holds attention with spectacle + danger-to-"you" (2.8 min dry stretch).
- Joke types: narrator persona w/ motive (SP evil AI "Hello mortals"); anticlimax shrug words ("So about that," "you're welcome"); literal/fake definition then real one; personified physics (electrons "enjoying private space", immune system "chose violence"); hyperbolic mundane simile w/ absurd modifier ("ghost marshmallow that goes to the gym"); list twist item; repetition-with-twist loop ("Too fast. Black hole. Not uniform. Black hole. Mercury in retrograde… black hole."); roast of scientists' naming; test-dummy victim (Jon falls in); fake double-take ("Wait. Huh?"); register parody (jargon salad → "I'm glad you asked"); perspective flip (aliens make horror movie about us); tonal flip ("Beautiful! And unsettling.").
- Key: every joke is ABOUT the fact being explained. Ours could be pasted into any video.
- Hooks: everyday version → cosmic version ("cheese holes, sink holes, plot holes, the other nostril hole… but a family of holes unlike the rest"); thriller-as-fact; "you + portal" journey "each stranger than the last"; false binary.
- Fact delivery: Earth anchor first then cosmic twist; question → answer; number → household-unit translation (bananas); fact sandwich.
- "You" = physically placed inside the physics (standing on surface, falling in, holding flashlight), NOT life complaints.
- Rhythm: long-long-short; fragments for awe ("Earth. Warm and pleasant.") and jokes ("Wait." "Huh?").
- Delivery: SP 171 wpm 4.6–8 long pauses/min; KZ 162 wpm 5–10/min. Punch jokes: long beat before AND after. Throwaway asides: no pause, running speed. Section change: // + short title line. Awe lines: slow via extra / between short phrases; hold back last word ("time to // leave // the clouds of // Nimbus").
- Endings: sincere wonder, no joke in last 30–60 s. Journey/ranking frames give built-in escalation.
- Avoid: "Science is mostly maybe in a lab coat" style hedges that make claim pointless → state doubt concretely (who says no and why). Ending on joke kills awe.
- Demo lines: "Black holes have one rule. Stuff goes in. Nothing comes out. Not light. Not information. Not that sock you threw at one." / "you'd cross the edge without spilling your tea" / "The galaxies declined to comment." / "every black hole up there is a door. And on the other side, somebody's sky. … Wondering which side is the inside."

## Past Tense (PT) — structure benchmark (not comedy: ~0.8 light moments/min)
- 1M+ videos ~joke-free; work via 2nd-person present-tense scene, "It's not a law. It's a story." reframe, escalating counter/refrain, bookend callback (7/8 videos).
- Hooks: everyday ritual exposed ("You never questioned it." → deny obvious reasons x3 → reframe → "Let us go back. Way back."); dream/fantasy → alarm undercut → "Statistically? Yes." → bigger question → method; the deal ("I have a trade offer" → you are now…→ escalate 3–4x → decision held to outro); small misfortune (cold pizza "somehow feels worse").
- Fact delivery: question/expectation → "They did not." → named evidence + number → "not X, it's Y" verdict (~25 in corpus).
- Density: wit opens and closes; middle runs on new facts + rising counter; max ~1.5 min without a "huh" beat. Wit always AFTER a fact, never mid-sentence.
- Pauses: ~50% inside numbers (split figure from magnitude "1 in 5.33 // quadrillion"); after jargon names; section changes; long pause AFTER punch, short / just before key word. Don't pause long before a weak punch (telegraphs). 172–180 wpm, flat delivery.
- Rhythm: fragments in threes ("Permanent settlements formed. / Cooking grew more complex. / Meals became more communal."); anaphora; climactic "Because… because… because…" recap; end warm address to viewer ("And now, you will know why.").
- 1-min shape: scene 8s → reframe 5s → mechanism 15s → evidence w/ number 12s → honest doubt 8s → callback 10s.

## Zenn — benchmark (our closest reference)
- ~1.1 humor beats/min overall; top videos (Night 8M 0.7/min, Calhoun 5M 0.35/min) fewest jokes; Aliens/All Day ~2/min. Every joke made from adjacent fact; ZERO generic relatable gags in ~90 min.
- Hooks: T1 switch flip (you do modern X tonight → 99.9% of history X didn't exist → sensory life without → so what did they do? → answer rewrites A, B, C = 3 sections); T2 perfect setup→disaster (N subjects got everything → time skip → all dead → not the obvious cause → "This is NAME, the most SUPERLATIVE…"); T3 odd one out (3 species fit perfectly → "And then there's us." → 3 failures → "what if"); T4 obvious question ("we know A, did B, even sent tourists → so why hasn't anyone just // DO IT?" → naive plan voiced → all failed, here's why); T5 second-person deflation ("at least that's how it feels" → what actually happened).
- Joke types: modern translation (~18: "a prototype that never got its final update"); deadpan undercut (~17: "retrofitted, / badly."); roast species/viewer; narrator aside ("This one's rough." "Seriously."); paraphrased quote; blunt taboo said flat; absurd specificity ("eight-legged gummy bears"); reductive redefinition ("Cooking is pre-digestion." "controlled rot"); rule-of-3 twist ("cameras… submarines… even tourists"); callback; misdirection reveal ("one craving we still have trouble admitting, // each other"); understatement ("to put it mildly, // not practical"); literal ("overnight. Literally."); fake ending ("So that settles it, right? Well, not quite.").
- Placement: ~70% jokes = closing line of a sub-beat (shortest sentence, last); 20% mid-sentence tags. Jokes cluster in first 40% evidence lists; last 15–20% always joke-free.
- Structure Night: cold open 0–6% → question + 3-part promise 6–8% → §1 → re-hook 19% "But here's what's fascinating" → §2 → re-hook at viewer 35% → §3 with twist → villain reveal 68% "So what killed it? … Light." → bonus "part nobody talks about" 74% → cost to YOU 81% → reframe twist 91% → lyrical recap + callback. Calhoun: paradox open → backstory+thesis question → act break 26% → 3 escalations → peak named characters → countdown → popular reading strawman 73% → twist "not what Calhoun actually said" 78% → twist 2 89% → callback to opening numbers "We still do."
- Fact delivery: claim/question → "In [YEAR], // [job] [Name] at [place]" → method one sentence → number → 3–5 word restatement ("This wasn't insomnia. This was normal.") → link to "you".
- Rhythm: mean 10.5–12 words, median 9–11; 18–26% ≤5 words; fragments as punches ("Everything." "Light."); rhetorical questions sparse at hook/pivots; "you"-mode (body/psych, 7–13/min) vs case-file mode (stories, third person, "us" only last 20 s); anaphora.
- Delivery: 186–208 wpm; long pauses only 0.4–2.9/min (rare!); long pause BEFORE punch/twist; second pause after only at section change or dark reveal; questions pause after before answer. "Rush the pivot, brake on the punch": punch words isolated ~1 s each ("Everything." "Light."), punch sentence ~104 wpm; connectives ("But not every male went quiet.") ~300 wpm; asides flat same register, no pauses.
- Ending: callback to first image changed, turned on viewer ("We still do."); no CTA.
- Demo: "Right now, you're inside something. / A room. / A city. / A planet. / A galaxy. // Some physicists think the list keeps going. (slow) The next item / is a black hole." … "No sign saying 'Now leaving reality.'" … "Most astronomers say: probably nothing. Wait for more data. / Fair." … ending reruns list with "A black hole. // Looking out / at all the others." Facts: Popławski 2010 bounce; Shamir 2025 JADES 263 galaxies ~2/3; size match = rough (Hubble radius).
